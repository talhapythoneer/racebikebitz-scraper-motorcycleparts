# racebikebitz.com Scraper

Built by [Talha Pythoneer](https://www.talhapythoneer.com), web scraping and AI agents.

## Overview

Hi, it's Talha (Pythoneer)

This project scrapes product data from [racebikebitz.com](https://racebikebitz.com/) (Samco Sport hose kits, clamps, coolant and related motorcycle/ATV parts) across all categories listed in `config.json`, visiting each product page to extract per-variant price, SKU and stock status, and writes the results to a Shopify product-CSV-compatible file (`racebikebitz_Data.csv`).

It is designed so that even if you are not a developer, you can set it
up by following the steps below. If you feel stuck at any step, feel free to ping me!

# Windows Setup

## 1. Install Python

Download and Install Python **3.13** from the official Python website.

During installation, enable **Add Python to PATH**.

## 2. Open Command Prompt

Open the project folder.

Type **cmd** into the address bar and press Enter.

## 3. Install Dependencies

``` bash
pip install -r requirements.txt
```

## 4. Configure the Project

If a config file is included, open it with any text editor and
update the required input values.

## 5. Run the Project

Example:

``` bash
python racebikebitz.py
```

# macOS Setup

## 1. Install Python 3.13

Install Python from the official website.

## 2. Open Terminal

Navigate to the project folder.

``` bash
cd /path/to/project
```

## 3. Create a Virtual Environment

``` bash
python3 -m venv .venv
```

## 4. Activate It

``` bash
source .venv/bin/activate
```

## 5. Install Dependencies

``` bash
pip install -r requirements.txt
```

If needed, use:

``` bash
pip3 install -r requirements.txt
```

## 6. Configure the Project

Edit the configuration file if required.

## 7. Run the Project

``` bash
python3 racebikebitz.py
```
